# rss-reader

CLI RSS/Atom feed reader with multi-feed support, RSS 2.0 and Atom parsing, and save/manage feeds.

## Installation

```bash
git clone https://github.com/will-work-for-bitcoin/rss-reader.git
cd rss-reader
```

## Usage

```bash
python rss_reader.py
python rss_reader.py --help
```

## Features

- Pure Python 3.7+, zero dependencies
- JSON/CSV export support
- Beautiful terminal output
- Easy to extend and customize
